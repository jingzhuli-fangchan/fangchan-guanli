# 小景·房产工作台

给大连房产经纪小景做的房源 + 客源管理工具，手机浏览器打开就能用。

## 功能

- 🏠 **房源管理**：录入/编辑/删除房源，小区、区域、总价、面积、户型、楼层、朝向、装修、房东电话、状态（在售/已售/暂缓），自动算单价
- 👥 **客源管理**：姓名、电话、微信、抖音号、需求区域、预算、意向度、来源、跟进状态，一键打电话
- 🔗 **房客匹配**：选客户自动找出区域+预算对得上的在售房源；选房源找出可推荐的客户
- 📊 **统计**：在售套数、总货值、待跟进人数、本月新增
- 💾 **备份**：导出/导入 JSON，换手机不丢数据

## 使用

打开 GitHub Pages 地址即可使用，数据保存在本机浏览器（localStorage），不经过任何服务器。

## 技术

单文件纯前端（HTML + CSS + JavaScript），零依赖，可离线使用。
